🕯 Alma Bohemia – E-commerce
📌 Descripción

Alma Bohemia es una aplicación web desarrollada para un emprendimiento de velas de soja.
Permite a los usuarios explorar productos, agregarlos al carrito y gestionar compras con persistencia en base de datos.

Proyecto desarrollado con enfoque en arquitectura modular, manejo de estado global y experiencia de usuario responsive.

🚀 Demo

🌐 https://alma-bohemia-swart.vercel.app/

🛠 Tecnologías Utilizadas

React

Vite

Redux Toolkit

Firebase (Authentication & Realtime Database)

Tailwind CSS

React Router

Git & GitHub

Deploy en Vercel

✨ Funcionalidades

Registro e inicio de sesión de usuarios

Carrito de compras dinámico

Persistencia de datos en Firebase

Gestión de estado global con Redux Toolkit

Componentes reutilizables

Diseño responsive adaptable a dispositivos móviles

Navegación dinámica con React Router

🧠 Arquitectura

Separación por componentes reutilizables

Manejo centralizado del estado global

Integración con base de datos en tiempo real

Estructura organizada por features
